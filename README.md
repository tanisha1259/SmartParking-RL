# Smart Parking Allocation System

An intelligent parking allocation system using Reinforcement Learning to optimize parking efficiency, reduce congestion, and minimize vehicle search time in smart urban environments.

---

## SDG Mapping
SDG 11 – Sustainable Cities and Communities

This project aims to reduce unnecessary congestion, fuel wastage, and parking inefficiencies through intelligent parking slot allocation.

---

## Reinforcement Learning Methodology

### Algorithm Used
Q-Learning

### Exploration Strategy
Decaying Epsilon-Greedy Exploration

### State Space
- Number of free parking slots
- Occupancy status

### Action Space
- Parking slot allocation

### Reward Function
- Higher rewards for efficient nearby parking allocation
- Lower rewards for inefficient slot assignment

---

## Features
- Parking simulator
- Dynamic incoming vehicle generation
- Reinforcement Learning-based slot allocation
- Reward tracking and visualization
- Policy saving using pickle
